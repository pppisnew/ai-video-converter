# 转换页布局与队列交互优化（2026-10-12，第十轮）

用户给出完整方案（布局独立滚动 / 箭头展开 + 选中联动 / 展开区瘦身 / 媒体信息分层），
并明确「展开项高度 ≤ 200px」「队列 20 个文件时右侧面板始终可见」等验收点。

## 二、实施中的判断（与用户字面方案有出入的地方，需在验收时确认）

1. **齿轮不等于展开按钮——齿轮保留**
   用户以为齿轮是展开/收起（实际它是「逐项参数覆盖」的入口，P5 已验收 + 有持久化 + 有回归测试）。
   处理：**新增** `▼/▲`（`ExpandToggleButton`），齿轮**下移到展开区底部**那一行（与「输出到」同行），
   `AutomationId` 与 Flyout 内容全部不变。这样既满足"点箭头展开/收起"的诉求，又不回退已交付功能。
2. **`MetaLine` 不动**
   用户的第一层摘要示例是 `00:17 · 720×1280 · 1.7 MB`，而现有 `MetaLine`
   已是 `1.7 MB · 720 x 1280 · MP4 → MP4 · 中等`（摘要 + 转换箭头 + 质量档位）。
   它是转换页与任务列表页**共用**的字段，且有多条断言它的单测。
   处理：保持 `MetaLine` 原样充当第一层摘要行，展开区只放 6 个技术字段（时长/分辨率已在摘要行里）——
   这就是「4 行压成 3 行」的落点，避免为纯文案差异制造跨页测试改动。
3. **输出路径的位置**
   字面要求「与文件名同行、文件名下方小字」。实际改为**展开区底部一行小字**（`输出到 <path>`，省略号 + ToolTip 全路径），
   与齿轮同行，不再独占带标签的一行。理由：折叠状态下列表每一行都显示几乎相同的输出路径，只会增加噪音；
   展开区一行小字既满足"不独占大行"，也不把信息藏起来。
4. **缩略图时间点 + 重新截取 → 右侧设置面板**
   用户给了二选一（移面板 / 压到缩略图下方）。选移到面板：展开区省掉约 37 DIP 才能稳定落在 200 DIP 以内；
   两个控件本来就是"选中项"语义（绑定 `ViewModel.ThumbnailPosition` / `CaptureThumbnailCommand`），
   放在面板里只需一份实例，不必在每个 `DataTemplate` 里各来一份。
5. **窄窗（<1100 DIP 单列）必须有整页滚动**
   宽窗"整页不滚"是方案的核心收益，但单列堆叠时队列与面板不可能同时塞进视口。
   处理：保留页面最外层 `ScrollViewer`，按断点在「宽窗：禁用整页滚动 + 队列/面板各自滚动」与
   「窄窗：启用整页滚动 + 内部滚动关闭」之间切换（沿用 spec 的代码后置断点，不用 VisualStateManager）。
6. **任务列表页的真实缺陷**
   `QueuePage` 根是 `Grid`（外层没有 `ScrollViewer`），列表却写着 `VerticalScrollMode="Disabled"`
   → 任务超过一屏时后面的行**根本滚不到**。本轮一并修掉（这是布局 4 的实质内容）。

## 三、文件边界（并行改动的隔离）

## 四、验收点（对应第一节，逐条留证据）

1. 队列 20 项时右面板（含「开始转换」）始终可见，整页不滚动
2. 齿轮已变为 `▼/▲`，点击能展开/收起媒体信息
3. 点击队列项 → 自动展开；手动收起后切换选中不强制展开
4. 展开项高度 ≤ 200 DIP（1180×800 第 1 项实测，UIA 读 `BoundingRectangle`）
5. 切换选中项时媒体信息随行刷新（多项可同时展开）
6. 任务列表页独立滚动，统计卡与筛选栏固定
7. 队列为空或 1 项时无异常空白、无滚动条
