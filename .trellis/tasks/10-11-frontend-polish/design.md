# 前端优化：控件重构与信息层级

## Goal

重构 WinUI 3 界面，达到"简约、清晰"的成熟桌面工具水准：降低单屏信息密度，
详情用渐进方式展示，优先使用 WinUI 官方控件。

## 现状问题（用户实测反馈）

1. 三列布局挤在一屏，信息密度过高：左队列 + 中 10 项媒体信息 + 右参数面板同时呈现
2. "输出目录"输入框被占位符文案伪装成标签，用户找不到
3. 控件风格简陋，缺乏统一的分组与层级

## 设计要求（用户原话）

- 参考成熟项目的控件，核心要求是**简约、清晰**
- **控制用户一次性得到的信息量**，控制在合理范围，详细信息用其他办法展示（如点击展开）
- 前端组件尽量使用框架/官方组件，避免问题

## 重构方案

### 布局：三列 → 两列

```
┌────────────────────────────────────────────────┐
│ 标题栏 + ffmpeg 状态 InfoBadge                   │
├───────────┬────────────────────────────────────┤
│ 文件队列   │  ┌─ 当前文件卡片 ───────────────┐  │
│ (固定宽度) │  │ 缩略图 | 文件名/时长/分辨率    │  │
│           │  │ [详细信息 ▾] Expander         │  │
│ 选择文件   │  │   → 展开后才显示 10 项元数据   │  │
│ 拖放区     │  └──────────────────────────────┘  │
│           │  ┌─ 转换设置卡片 ───────────────┐  │
│ 工具栏     │  │ 容器格式 / 视频编码器 / 质量  │  │
│ (全选/移动 │  │ [高级选项 ▾] Expander         │  │
│  /移除/    │  │   → 分辨率/音频码率/输出目录  │  │
│  清除/清空)│  └──────────────────────────────┘  │
│           │  [开始转换] [取消当前] [全部停止]   │
│ 队列列表   │  [进度条 + 汇总]                   │
└───────────┴────────────────────────────────────┘
```

### 信息层级（渐进展示）

| 区域 | 默认展示 | 展开后展示 |
|---|---|---|
| 当前文件 | 缩略图、文件名、时长、分辨率 | 完整 10 项元数据（帧率/编码/声道/码率/大小/容器） |
| 转换设置 | 容器格式、视频编码器、质量滑杆 | 分辨率、音频码率、输出目录 |

### 官方控件选用（已核实存在于 WinAppSDK 2.5.1）

- `Expander` — 原生 WinUI，用于两级信息展示（替代手工写的展开逻辑）
- `InfoBadge` — 原生 WinUI，用于 ffmpeg 状态与队列计数徽标
- `Card`/`Border` + `CornerRadius` — 统一卡片容器风格
- 移除自造的灰色小字堆叠，统一用官方排版样式

### 其他修复

- 输出目录输入框去掉误导性占位符，空态即"与源文件同目录"
- 队列行压缩为单行：复选框 + 文件名 + 状态徽标（进度并入徽标）

## Acceptance Criteria

- [ ] 单屏默认只展示：队列、当前文件摘要、核心 3 项参数、操作按钮
- [ ] 点击"详细信息"/"高级选项"才展示次要信息，使用官方 Expander
- [ ] ffmpeg 状态使用 InfoBadge 展示
- [ ] 输出目录可找到且可编辑
- [ ] 全部交互控件保留 AutomationId（不破坏既有自动化）
- [ ] 142 个既有测试保持通过

## Out of Scope

- 新增功能（转换能力不变）
- 换肤/主题定制
