# 前端优化：控件重构与信息层级

## Goal

重构 WinUI 3 界面，达到"简约、清晰"的成熟桌面工具水准：降低单屏信息密度，
详情用渐进方式展示，优先使用 WinUI 官方控件。

## 现状问题（用户实测反馈）

1. 三列布局挤在一屏，信息密度过高：左队列 + 中 10 项媒体信息 + 右参数面板同时呈现
2. "输出目录"输入框被占位符文案伪装成标签，用户找不到
3. 控件风格简陋，缺乏统一的分组与层级

## 设计要求（用户原话）

- 参考成熟项目的控件，核心要求是**简约、清晰**
- **控制用户一次性得到的信息量**，控制在合理范围，详细信息用其他办法展示（如点击展开）
- 前端组件尽量使用框架/官方组件，避免问题

## 重构方案

### 布局：三列 → 两列

```
┌────────────────────────────────────────────────┐
│ 标题栏 + ffmpeg 状态 InfoBadge                   │
├───────────┬────────────────────────────────────┤
│ 文件队列   │  ┌─ 当前文件卡片 ───────────────┐  │
│ (固定宽度) │  │ 缩略图 | 文件名/时长/分辨率    │  │
│           │  │ [详细信息 ▾] Expander         │  │
│ 选择文件   │  │   → 展开后才显示 10 项元数据   │  │
│ 拖放区     │  └──────────────────────────────┘  │
│           │  ┌─ 转换设置卡片 ───────────────┐  │
│ 工具栏     │  │ 容器格式 / 视频编码器 / 质量  │  │
│ (全选/移动 │  │ [高级选项 ▾] Expander         │  │
│  /移除/    │  │   → 分辨率/音频码率/输出目录  │  │
│  清除/清空)│  └──────────────────────────────┘  │
│           │  [开始转换] [取消当前] [全部停止]   │
│ 队列列表   │  [进度条 + 汇总]                   │
└───────────┴────────────────────────────────────┘
```

### 信息层级（渐进展示）

| 区域 | 默认展示 | 展开后展示 |
|---|---|---|
| 当前文件 | 缩略图、文件名、时长、分辨率 | 完整 10 项元数据（帧率/编码/声道/码率/大小/容器） |
| 转换设置 | 容器格式、视频编码器、质量滑杆 | 分辨率、音频码率、输出目录 |

### 官方控件选用（已核实存在于 WinAppSDK 2.5.1）

- `Expander` — 原生 WinUI，用于两级信息展示（替代手工写的展开逻辑）
- `InfoBadge` — 原生 WinUI，用于 ffmpeg 状态与队列计数徽标
- `Card`/`Border` + `CornerRadius` — 统一卡片容器风格
- 移除自造的灰色小字堆叠，统一用官方排版样式

### 其他修复

- 输出目录输入框去掉误导性占位符，空态即"与源文件同目录"
- 队列行压缩为单行：复选框 + 文件名 + 状态徽标（进度并入徽标）

## Acceptance Criteria

- [ ] 单屏默认只展示：队列、当前文件摘要、核心 3 项参数、操作按钮
- [ ] 点击"详细信息"/"高级选项"才展示次要信息，使用官方 Expander
- [ ] ffmpeg 状态使用 InfoBadge 展示
- [ ] 输出目录可找到且可编辑
- [ ] 全部交互控件保留 AutomationId（不破坏既有自动化）

## UI 重构方案（2026-10-11 用户确认）

调研结论见 `research/ui-references.md`。用户确认：

- **导航三项**：转换 / 队列 / 设置。拆分理由：原右列挤了五组内容（编码器卡+参数面板+摘要+操作+进度），
  是拥挤根源；设置类内容（编码器探测、输出目录、ffmpeg 管理）需要独立归属页面。
- **改造顺序**（第 3 步合并队列修复，避免队列 UI 改两遍、测两遍）：
  1. NavigationView + Frame 骨架（三页 + InfoBadge）
  2. 全局 Overrides.xaml 样式表（三主题字典）
  3. 队列页重构 + BUG-02/03/04/05 修复合并（卡片化/复选框/排序/删除/清除/定位/一键开始 + 状态源统一）
  4. 转换页重排（设置内容迁出后重新布局）
  5. 轻量按钮与图标混排
- 用户要求：第 1 步骨架完成后先截图确认再继续，避免方向偏了返工
- 用户要求：UI 重构后重跑全部功能验收清单；在 session-summary 记录决策依据

### 三页职责划分

| 页面 | 职责 |
|---|---|
| 转换 | 选择/拖拽文件、媒体信息、缩略图、参数面板、开始转换 |
| 队列 | 任务列表、四态流转、勾选、排序、单项删除、清除已完成、定位产物、失败汇总 |
| 设置 | 编码器状态、强制软件编码、重新探测、输出目录、ffmpeg 来源与版本 |

队列运行时在"队列"导航项用 InfoBadge 显示 运行中/等待中 数量。
