# 按原型重做前端：映射规格（2026-10-12）

原型：`prototype/视频转换器原型.html`（用户提供，70KB，WinUI 3 风格 HTML 原型）

## 原型与当前实现的差异（关键）

上一轮我按用户方案 A 把「开始转换」只放在队列页；**原型把它放回转换页**，
并把原「队列」页改造成带统计卡与筛选的「任务列表」监控页。以原型为准。

| 区域 | 原型 | 当前实现 | 处理 |
|---|---|---|---|
| 导航 | 转换 / **任务列表** / 设置 + 底部状态脚 | 转换 / 队列 / 设置 | 改标签为「任务列表」；把 ffmpeg 状态移到导航底部（原窗口头部） |
| 页标题 | 页内 page-head（28px 标题 + 14px 副标题） | 窗口头部统一显示 | 改回页内标题，移除窗口头部标题带 |
| 转换页 | 左：拖放区 + 队列列表；右：372px 输出设置面板 + 开始转换 | 单文件预览 + 参数卡 | 按原型重做 |
| 任务列表 | 4 张统计卡 + 状态筛选 + 任务行（进度/速度/行内操作） | 工具栏 + 队列卡片 | 按原型重做 |
| 设置页 | 两列分组卡（常规/转换/界面/关于） | 两列分组（编码器/ffmpeg/输出） | 按原型重排为两列分组 |
| 反馈 | 右下角 toast | 底部状态栏 | 改为右下浮层提示（不占布局高度） |

## 本次实现范围（映射到现有真实能力）

6. `Overrides.xaml` 补齐按钮/输入/徽章/进度/卡片/设置行样式，对齐上面的令牌
7. **媒体信息保留**：原型没有单文件信息区，但原始需求 1 要求"加载视频信息并显示缩略图"，
   因此在左列队列下方保留一个**默认折叠**的 `媒体信息` Expander（缩略图 + 10 项字段 +

**不做的（原型有、但当前没有对应能力，做了就是假开关）**，需向用户说明：

- 主题切换（浅色/深色/跟随系统）、语言切换 —— 原设计文档已列为 Out of Scope

- 每个任务独立的目标格式与质量下拉 —— 当前模型是"全局参数在任务开始时捕获并同步到待转换项"；

- 暂停/继续 —— 需要转换服务支持暂停，当前只有取消
- 托盘 / 系统通知 / 启动恢复 / 完成后打开文件夹 / 检查更新 / 开源许可 —— 新功能

### 验收中发现的三个问题（已修）

1. **1100 DIP 断点完全不生效**：VSM/AdaptiveTrigger 放在 `ScrollViewer` 内层的 Grid 上时
   不触发（放在页面最外层 Grid 才生效，HEAD 版本正是后者）。1000 DIP 下仍是两列，
   800 DIP 下左列内容被裁切（"支持批量添加 MP4 / MKV / AVI / MOV /" 被截断）。
   改为 `SizeChanged` + `XamlRoot.Size.Width` 的代码式断点，确定生效。
2. **状态/toast 文字在浅色主题下几乎不可见**：VM 里 `NormalTextBrush` 硬编码为 #E6E6E6
   （为深色主题写的）。改为从主题资源解析（`TextFillColorPrimaryBrush` /
   `TextFillColorSecondaryBrush` / `SystemFillColorCriticalBrush`）。
3. **`ClearQueueButton` 在转换页丢失**：补回新面板的「清空队列」按钮上。

另修：任务行元信息缺少「分辨率 · 源格式」之间的分隔符。

### 与原型的有意偏差（需用户知晓）

- **每行缩略图是占位图标**：模型只有"当前选中项"的一张缩略图（`MainViewModel.Thumbnail`）。
  要做到原型那样每行真实帧，需要入队时为每个文件各截一帧（每个文件一次 ffmpeg 调用）。
  本轮未做，留给下一轮决定。
- **保留「媒体信息」折叠区**（原型没有）：原始需求 1 要求"加载视频信息并显示缩略图"，
  因此把真实缩略图 + 10 项字段 + 重新截取放在队列下方的折叠区里；默认折叠以贴合原型观感。
  注意：折叠内容不会被 UIA 实例化，自动化需要先展开才能取到 `RecaptureButton`。
- **质量用 CRF 滑杆**（原型是质量预设下拉）：保持数值透明，与既有参数摘要一致。
- **未实现**：主题/语言切换、并发数、帧率、字幕/章节、逐项格式下拉、暂停/继续、
  托盘/通知/启动恢复/检查更新，以及自定义标题栏（WinUI 保留系统标题栏）。
