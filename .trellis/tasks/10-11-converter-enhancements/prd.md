# 增强：批量队列、编码参数面板与硬件加速

## Goal

在已验收的 MVP 基础上增加三项核心能力：批量转换队列、全局编码参数面板、
硬件加速自动探测与回退。目标是让产品从"能转换"变成"能当日常工具用"。

## Background / Confirmed Facts

- 前置：MVP（任务 `10-10-video-converter`）已通过用户实测验收，
  含单文件加载/信息/缩略图/固定预设转换/进度/取消/ffmpeg 捆绑
- 用户 2026-10-11 确认三项决策均为推荐方案（AAA），并给出细化要求：
  - 队列顺序处理（理由：ffmpeg 默认吃满全部 CPU 核心，多文件并行只会互相抢 CPU 和磁盘 I/O，
    总耗时不会减半；除非做分段并行，否则并行在编码场景几乎无收益）
  - 队列项四态：等待中 / 转换中 / 已完成 / 失败；当前任务高亮；已完成项可定位到输出文件
  - 全局参数（理由：可"先调好参数再拖文件"，避免"改的是全局还是这一个"的认知负担）
  - 参数面板保留"重置为默认"，并显示参数摘要
  - 硬件加速必须**真实试编码**探测，不能只查 `-encoders` 列表
  - 探测结果缓存到本地，提供"重新探测"
  - 保留"强制使用软件编码"手动开关
  - 硬件编码器必须按"编码器 × 编码格式"组合分别探测
- 硬件调研结论见 `research/hardware-accel-survey.md`：
  本机 RTX 4050（驱动 591.74）上 NVENC/QSV/AMF **全部不可用**
  （NVENC 需驱动 610+，无 Intel/AMD GPU），只有软件编码器可用——
  这恰好证明了"真实试编码 + 软件回退"是必需设计
- 破坏性变更：`ConvertPreset` / `IConversionService` 契约需调整（用户已给出迁移方案）

## Requirements

- R1 批量队列：支持多文件入队（选择/拖拽均可追加），顺序处理，
  队列项有 等待中/转换中/已完成/失败 四态，当前任务高亮
- R2 队列操作：可移除单个队列项、清除已完成、重试失败项；
  一个任务失败不中断后续任务（用户明确关注点）
- R3 已完成项可定位到输出文件（在资源管理器中打开所在目录）
- R4 全局参数面板：容器格式（MP4/MOV/MKV/AVI/WebM/MP3）、
  视频编码器（Auto/H.264/H.265/AV1/VP9）、质量（0-51，默认 23）、
  分辨率缩放（原始/1080p/720p/480p）、音频码率（kbps）
- R5 参数摘要：面板内实时显示当前参数组合摘要（如"H.265 · CRF 23 · 原始分辨率 · 音频 128k"），
  提供"重置为默认"
- R6 硬件加速：启动后异步探测，结果缓存；按 H.264→H.265→AV1→VP9 ×
  NVENC→QSV→AMF 组合探测；全不可用则软件回退；界面显示当前实际编码器；
  提供"强制软件编码"开关与"重新探测"
- R7 探测缓存失效策略（用户明确关注点）：ffmpeg 路径/版本变化、缓存超期、
  缓存损坏、手动重新探测、运行时硬件编码失败，任一发生即失效并重新探测
- R8 运行时兜底：硬件编码实际转换失败时，自动改用软件编码重试该任务，
  并把对应编码器标记为不可用
- R9 现有单文件 MVP 能力全部保留（加载信息、缩略图、进度、取消、ffmpeg 捆绑）

## Acceptance Criteria

- [ ] AC1 连续添加多个视频后全部进入队列，按顺序逐个转换，同一时刻只有一个任务在转
- [ ] AC2 队列项状态正确流转，失败项不影响后续任务继续执行
- [ ] AC3 点击已完成项能在资源管理器中定位到输出文件
- [ ] AC4 修改任意参数后，参数摘要实时更新；点"重置为默认"恢复初始值
- [ ] AC5 用 H.265 / AV1 / VP9 编码能产出可播放文件（本机为软件编码）
- [ ] AC6 质量参数与分辨率缩放真实生效（可用 ffprobe 验证分辨率变化）
- [ ] AC7 启动时自动探测，界面显示"当前编码器：xxx"；本机应显示软件编码器
- [ ] AC8 强制软件编码开关生效；重新探测按钮可重跑探测
- [ ] AC9 探测缓存第二次启动被复用（不重复试编码），ffmpeg 版本变化后自动重新探测
- [ ] AC10 单文件 MVP 全部原有行为不回退（回归）

## Out of Scope

- 分段并行转码（同一文件切段并行）——收益高但复杂度高，记录备查
- 字幕封装、滤镜、HDR/色彩空间转换
- 队列项级独立参数（已决策为全局参数）
- 硬件解码（-hwaccel）

## Open Questions

无阻塞性问题。三项产品决策已由用户确认（AAA）。
